Circuit

Each string gets its own resistor. Parallel LEDs sharing one resistor don't split the current evenly, so one LED can end up over-driven.

Results

LED current (= string current) ILED = PLED / VLED
String voltage Vstring = nseries × VLED
Voltage to drop ΔV = Vsource − Vstring
Required resistance (per string) R = ΔV / ILED
Resistor power rating (each) PR = ΔV × ILED
Total current from source Itotal = nparallel × ILED
Total power from source Ptotal = Vsource × Itotal
Power in LEDs / efficiency nseries × nparallel × PLED

    Notes: a resistor is a simple way to limit LED current, but it wastes ΔV × I as heat. For high-power LEDs (1 W and up) a constant-current driver is usually more efficient. The LED forward voltage varies between parts — check your datasheet.
